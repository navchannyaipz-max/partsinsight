# PartsInsight — аналітична система пошуку автозапчастин в Інтернеті

Flask + SQLite (Python 3.9+). Пошук виконується **наживо в Інтернеті**: під час кожного запиту система паралельно
звертається до підключених джерел (HTTP), розбирає відповіді, нормалізує артикули, визначає рівень
відповідності (IDENTICAL / CROSS_REFERENCE / CANDIDATE) і рахує цінову аналітику (розділ 2 роботи).
Імпорту файлів немає. Кеш (15 хв) лише скорочує повторні запити; кнопка «оновити з Інтернету» його обходить.

## Запуск
    pip install -r requirements.txt
    ADMIN_PASSWORD=ваш_пароль python run.py      # http://127.0.0.1:5000
    pytest                                       # 14 тестів

Змінні: `ADMIN_PASSWORD` (за замовч. admin — змініть), `SECRET_KEY`, `DATABASE`, `BASE_URL`.

## Два види інтернет-джерел (адмін-панель «Джерела»)
1. **HTML** — сторінка пошуку магазину; профіль JSON: `item` (CSS-селектор картки) і `fields` (`селектор@атрибут`).
2. **JSON API** — `items_path` і `fields` (шлях через крапку), ключ у `api_key`/`headers`.
Профіль редагується без зміни коду. Нове джерело додається вимкненим — спершу натисніть «Тест».
Клієнт поважає robots.txt, має паузу між запитами, таймаут, ліміт розміру, блокує внутрішні адреси (SSRF).

## Демо-«Інтернет»
`/mock/...` — три локальні джерела (2 HTML з різною версткою + JSON API) з вигаданими даними. Запити до них
ідуть справжнім HTTP тим самим кодом, що й до зовнішніх сайтів. Два джерела-шаблони з example.com вимкнені.

## Структура
app/normalize.py (артикули, виробники, триграми) · matching.py (рівні, H, S) · analytics.py (p*, Up/Ud/Uf,
Score, MAD/Z) · fetcher.py (HTTP + адаптери) · service.py (оркестрація, групи, кеш) · mock_web.py · templates/ · static/
design-system/partsinsight/MASTER.md — дизайн-токени (ui-ux-pro-max).

## Підключення реальних джерел
1. **Офіційний API (рекомендовано).** Пресет «eBay Browse API»: отримайте ключі на developer.ebay.com і запустіть
       export EBAY_CLIENT_ID=...  EBAY_CLIENT_SECRET=...
       python run.py
   потім в адмін-панелі увімкніть джерело. Секрети в БД не зберігаються: у профілі пишеться `"$ENV:ІМ'Я"`.
   Підтримуються OAuth2 client-credentials (`auth`) і статичний ключ (`api_key` + `headers`).
   Якщо в API немає поля «артикул», використовується `"mpn_from_title": true` (артикул шукається в назві).
2. **HTML-сайт.** «Додати джерело» → URL пошуку з `{q}` → CSS-селектори. Кнопка **«Тест»** показує HTTP-статус,
   кількість знайдених карток і перші розібрані записи — так селектори підбираються за кілька хвилин.
   Сайти, які будують сторінку JavaScript-ом, цим способом не читаються — для них потрібен API.
Перед підключенням сайту перевірте його robots.txt та умови використання. Для офіційного API з авторизацією
robots.txt не застосовується, для HTML — застосовується завжди.

## Ключі API (отримання)
* **eBay:** developer.ebay.com → Register (безкоштовно) → підтвердити e-mail → My Account → Application Keys →
  створити Production keyset → Client ID і Client Secret. Для production eBay вимагає налаштувати Marketplace Account
  Deletion notification або подати запит на звільнення від нього.
* **SerpApi (Google Shopping):** serpapi.com → реєстрація → API key → `export SERPAPI_KEY=...`.
