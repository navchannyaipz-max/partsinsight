# Комплект приймання PartsInsight (за ТЗ)

## 1. Запуск
1. macOS: двічі клацнути `start.command`; Windows: `start.bat`. Адреса: http://127.0.0.1:5050
2. Усі ключі вводяться у вебзастосунку: «Вхід» (футер) → «Ключі». Пароль адміністратора за замовчуванням `admin` — змінити.
3. Дані та налаштування лежать поза папкою програми: `~/PartsInsightData` (`partsinsight.db`, `backups/`, `errors.log`).
4. Автоматичні перевірки: `python -m pytest -q` (100 перевірок; F1–F3, R1–R3, фасування, доставка й міграція — `tests/test_acceptance.py`, E1 — `tests/test_e1.py`).

## 2. Приклад конфігурації джерела (профіль JSON, поля R2 необов’язкові)
```json
{
  "items_path": "data.items",
  "fields": {
    "title": "name", "url": "link", "mpn": "article", "brand": "brand",
    "price": "price.amount", "currency": "price.currency",
    "availability": "stock", "delivery": "delivery_days",
    "pack": "pack_qty", "shipping": "delivery.cost", "shipping_currency": "delivery.currency"
  },
  "shipping": {"cost": 80, "currency": "UAH", "free_confirmed": false}
}
```
* `pack` — кількість одиниць. Приймається лише підтверджене додатне ціле з поля джерела або однозначної назви («2 шт.», «пара»). Відсутнє, дробове (1.8), нульове чи суперечливе значення → **«Фасування невідоме»**: показується ціна оголошення й валюта, пропозиція не входить у ціну за одиницю, мінімум, медіану й вибір найдешевшої одиниці. Припущення «1 шт.» не робиться.
* `pack_default` (необов’язково, лише явне рішення адміністратора джерела): `"pack_default": 1` означає «усі пропозиції цього джерела — поштучні». За замовчуванням не задано. Налаштовано лише в демоджерелах.
* `shipping_free: true` у відповіді джерела (або `shipping.free_confirmed` у профілі) підтверджує безкоштовну доставку. `shipping` у полях пропозиції має пріоритет над `shipping` у профілі. Значення `0` вважається безкоштовною доставкою **лише** за `free_confirmed: true` у профілі (або поля `shipping_free` у відповіді); інакше — «Доставка уточнюється».

## 4. Протокол F4, U1, U2 (виконано на демоджерелах; повторити на реальному джерелі)
**F4.** (1) Живий пошук `0986452041`: картки мають назву джерела, «До продавця», час отримання, походження («живий пошук»), мітку «Демо». (2) Повтор: походження «кеш», час отримання **той самий**. (3) Недоступне джерело (адреса одного демоджерела замінена на недосяжну) + «оновити ціни»: сторінка показує «Частину джерел не вдалося опитати…», для недоступного джерела — «збережені дані» з початковим часом; у базі час кешу не змінився (`test_f4_failed_refresh_keeps_original_time`). Нуль збігів після успішної відповіді показує окремий стан «Джерела відповіли, але збігів не знайдено» (`test_f4_zero_matches_after_success_is_separate_state`).
*Статус:* кроки (1)–(3) виконано на демоджерелах; **крок для реального зовнішнього джерела автор виконує на своєму комп’ютері** (з пісочниці розробки доступу до Інтернету немає).

**U1.** Під рядком пошуку — вкладки «Усі / За артикулом / Аналоги / Можливі збіги» з кількістю груп. Картка: назва → виробник і артикул → рівень + підстава (текстом, без наведення) → діапазон цін і кількість продавців. «Аналоги» + «Лише в наявності» → деталі → назад: запит, виробник, обидва фільтри й порядок збережені (`test_u1_filters_survive_round_trip`); порожня комбінація → «Скинути фільтри» (зберігає запит).

**U2.** Порядок на сторінці деталі: ідентифікація й підстава → пропозиції з «До продавця» → розклад оцінки вибраної пропозиції (відсутня ознака: «Немає даних», фактична вага 0 %, ваги решти перераховано). Перевірено на ширині 390 і 1366 px: горизонтальної прокрутки сторінки немає (лише всередині таблиць), кнопка «До продавця» для найкращої пропозиції показана над таблицею; Tab-навігація проходить пошук, вкладки, «Стан джерел», розкриття; фокус видимий (суцільний контур).

## 6. Сценарій захисту
1. `0986452041` → дві групи «За артикулом» (нова й б/в), аналоги (Knecht OC 47, MANN W 719/30).
2. Скоротити до `0986452` → «Можливі збіги» з причиною «Спільний початок артикула (7 з 10 знаків)». Різниця: повний артикул дає збіг за ключем (виробник + артикул), скорочений — лише гіпотезу за префіксом без підтвердження.
3. Відкрити групу → відмітити 2–3 пропозиції → «Порівняти вибрані».
4. Закінчити таблицею E1 (`experiments/e1/runs/<run_id>/evaluation/e1_table.csv` і `e1_report.md`).
5. **Резерв без Інтернету:** заздалегідь виконати пошуки онлайн; кеш зберігає дату отримання. За недоступності джерел «оновити ціни» покаже ті самі пропозиції з позначкою «збережені дані» й початковим часом.

## 7. Статус F4 (відкрито) і протокол для вашого комп’ютера
З середовища розробки немає доступу до Інтернету, тому F4 на **реальному зовнішньому джерелі лишається відкритим**. Виконайте на своєму комп’ютері (джерело налаштоване й увімкнене, ключ введено у «Ключі»):
1. **Живий пошук:** відкрийте `0986452041`. Перевірте: у картках є назва джерела, «До продавця» (відкриває оголошення), час отримання, походження «живий пошук». Запишіть час.
2. **Повтор із кешу** (протягом 15 хв): повторіть той самий пошук без «оновити ціни». Перевірте: походження «кеш», час отримання **той самий**, що в кроці 1.
3. **Невдале оновлення:** вимкніть Інтернет (або тимчасово змініть адресу джерела на недосяжну в «Джерела») → «оновити ціни». Перевірте: банер «Частину джерел не вдалося опитати…», пропозиції з позначкою «збережені дані» та **початковим** часом з кроку 1.
4. Зробіть скриншоти й занотуйте результат у цьому розділі. Автоматична перевірка тієї самої поведінки на тестових даних: `test_f4_*` та протокол на демоджерелах вище.

## 8. Обмеження
* Реальна вибірка E1 **не збиралась**; `queries.csv` — чернетка (усі статуси «ЧЕРНЕТКА»), яку автор підтверджує до `freeze.py`. Взаємозамінність Q01/Q02 без незалежного каталожного джерела не заявляється (правило звужено до точного збігу). Результати реальної вибірки подаються окремо від локального експерименту на 48 запитах.
* Курси валют у коді фіксовані (UAH 1, USD 41,5, EUR 45): для іншої валюти ціну за одиницю не розраховано, причина показана.
* Через вимогу «без припущення 1 шт.» джерела без поля кількості (наприклад, SerpApi) показують ціну оголошення без ціни за одиницю, доки адміністратор явно не задасть `pack_default`.
* Старі записи архіву без атрибутів фасування/стану/походження/доставки позначаються «невідомо».
